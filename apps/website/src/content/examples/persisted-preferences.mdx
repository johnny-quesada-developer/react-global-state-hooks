## What to look for

- Choose an accent and a size. The box under **Saved in localStorage** shows what was written.
- The draft note appears in the preview but never in the saved data: the `selector` decides what is stored.
- Reload the page. Your choices come back; the draft does not.
- **Clear saved data** resets the store and rewrites the defaults.

## The code

`selector` picks what is saved. `validator` runs on every restore and keeps only values that are still
valid, so an old or edited value cannot break the page.

<Callout type="warning" title="Hydration">
  The store restores from `localStorage` when the module loads in the browser, which is before React hydrates
  this page's server-rendered HTML. The component therefore shows the defaults until hydration finishes, then
  the saved values. Rendering the saved values straight away would not match the HTML.
</Callout>
