and press **Retry**.

## What to look for

- The status moves through idle, loading, success and error. `attempts` counts every request.
- **Retry** is the same `load` action. A retry clears the previous error.
- The button is disabled while a request is in flight.

## The code

The store takes the fetch function as an argument. The demo passes a fake one, and the tests pass their own, so
the workflow is tested without timers or a network.

<CodeBlock code={store} lang="ts" title="store.ts" />

The request counter lives in **metadata**, because no component displays it. When two requests overlap, the
action compares its id with the latest one and drops the late answer.

<Callout type="warning" title="Keep the tools object whole">
  Inside an action, read `tools.metadata` when you need the current value. Destructuring
  `({ metadata }) => ...` copies the object at that moment, and it is out of date after `setMetadata`.
</Callout>
