## How the counters work

<Callout type="note" title="Counting renders under Strict Mode">
  React Strict Mode renders every component twice in development, which would double naive counters. The
  counter here counts commits in an effect, skips React's simulated remount, and updates its own element
  directly so counting never causes a render. The tests run the demo both with and without Strict Mode.
</Callout>
