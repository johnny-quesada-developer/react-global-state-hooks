button, and watch which counters move.

<SelectiveDemo client:visible />

## What to look for

- Typing a name renders the Name card and the whole-state card. Role and Clicks stay at their count.
- The whole-state card has no selector, so it renders for every change. That is the cost every component would
  pay if it subscribed to the whole store.
- Setting the state to the same object again renders nothing.

## How the counters work

<Callout type="note" title="Counting renders under Strict Mode">
  React Strict Mode renders every component twice in development, which would double naive counters. The
  counter here counts commits in an effect, skips React's simulated remount, and updates its own element
  directly so counting never causes a render. The tests run the demo both with and without Strict Mode.
</Callout>
