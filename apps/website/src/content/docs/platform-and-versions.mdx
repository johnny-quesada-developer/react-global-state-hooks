## Packages

| Package | Use it for | Persistence |
| --- | --- | --- |
| `react-global-state-hooks` | Web apps. | `localStorage` |
| `react-native-global-state-hooks` | React Native. | Async storage (optional peer dependency) |
| `react-hooks-global-states` | The shared core, without a storage layer. | None |

The web and React Native packages build on the core package and re-export its API.

## Requirements

- React 18 or newer (`react >= 18`). The core package also lists `react-dom >= 18`.
- The web package needs `json-storage-formatter` ^4 (installed with it).
- React Native: `react-native >= 0.69` and, for persistence, `@react-native-async-storage/async-storage >= 1.17.11`.

## Release channels

<Callout type="note" title="What is on npm">
  These docs cover <strong>{DOCUMENTED_VERSION}</strong>. On npm, `react-global-state-hooks` has
  `latest` = <strong>{STABLE_VERSION}</strong> and `beta` = <strong>16.0.4-beta</strong>. The runtime API is
  the same in both. The beta adds the <code>react-global-state-hooks/debug</code> entry for DevTools.
  `react-native-global-state-hooks` currently has `latest` = 15.0.3, and version 16 is available on the
  `beta` tag.
</Callout>

Install a channel explicitly with `npm install react-global-state-hooks@beta`.

## Server rendering

- On the server, `localStorage` is not available, so persistence is skipped and stores start from their
  initial state.
- A global store is a module singleton. On a server it is shared between requests; keep per-request data in
  a context instead.
- Persisted values restore before hydration in the browser. See [Persistence](../persistence/).
